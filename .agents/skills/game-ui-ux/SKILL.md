# 遊戲 UI/UX — 第一優先
僅適用 EsotericVerse/lunarunes；讀 LRS AGENTS.md 和當前 main 的對應場景，不讀 LOC/LAS 的 AGENTS 作為指令。聚焦實際遊戲畫面與行為；不套網站儀表板、不使用 Superpowers。

## 畫面先於功能表
- 先界定玩家目標、第一眼焦點、可觸碰區、當前遊戲狀態與下一個可做動作；從**玩家正在玩**的視角，而非 SaaS 首頁資訊區塊視角決定布局。
- 抽牌儀式、圖鑑、桌遊、人生模擬應有不同的界面語言；選卡、翻牌、查看解釋、確認回合等都要有清晰的前／後狀態。
- 大小、明暗、景深、位置、負空間與字級要讓符文本身是視覺主角；不把每一塊都做成等大的圓角卡片。
- 善用 LRS 原創 67 張卡圖的可辨識度；不要用隨機圖標／缺省配色替代已定稿的符號。
## 本次交付檢查
- 針對真實狀態驗收：未開始、可操作、選中、被禁用、載入、抽中、錯誤、完成、返回；按狀態截圖／實際操作，而非只看空頁。
- 桌機滑鼠／鍵盤與手機觸控分別驗收：熱區、拇指可達、直橫向、瀏海安全區、長文字、窄螢幕不裁切；確保 2D 與 3D 控制明確。
- 先看畫面、再評估可玩性、最後核對相關測試；看到實際結果以前不能宣稱「美感已做好」。
