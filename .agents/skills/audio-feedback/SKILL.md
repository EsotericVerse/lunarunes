# Game Audio / Feedback — 聲音是可選的遊戲層
僅適用 EsotericVerse/lunarunes；讀 LRS AGENTS.md 和當前 main 的對應場景，不讀 LOC/LAS 的 AGENTS 作為指令。聚焦實際遊戲畫面與行為；不套網站儀表板、不使用 Superpowers。

- 以玩家狀態設計音效：摸牌、選中、翻開、事件、結算分別應有清晰聲音語意；不把背景歌曲當「遊戲完成」的標準。
- 先查目前 LRS 是否已有音效來源和授權；**沒有就不能宣稱已具備音效引擎或素材**，更不可擅自取用非授權歌曲。
- 聲音與視覺回饋時間對齊，但不影響輸入回應、牌面內容或結算。提供靜音、音量偏好，且無聲也能完成所有動作。
- 手機的瀏覽器自動播放限制需尊重使用者手勢；不要開頁就大聲播放或在背景持續佔用音訊。
- 若本次需求沒有聲音，不為了裝 Skills 而新增播放器、遊戲音樂或依賴。
- 驗收：首次啟動、靜音、手機手勢啟用、返回、連續出牌，確認無重疊播放與持續背景音。
