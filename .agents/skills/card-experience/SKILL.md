# Card Reading Experience — 抽符文不是一般表單
僅適用 EsotericVerse/lunarunes；讀 LRS AGENTS.md 和當前 main 的對應場景，不讀 LOC/LAS 的 AGENTS 作為指令。聚焦實際遊戲畫面與行為；不套網站儀表板、不使用 Superpowers。

- 先呈現牌陣與選擇的空間關係；抽牌前、選定、揭示、解釋、回顧都有明確場景狀態。
- 只能使用已核准的 66 張可抽牌；第零符「德」不抽。原符文中文／英文／群組及方向位語意不能改寫以配合動畫。
- 四方向位：正、半正、半逆、逆；依現有抽牌規則定位圖像與內容，**圖鑑瀏覽不需要附帶方向位**。
- 區分 1／2／3／5／11 抽及自訂牌陣，不得因共享 UI 就合併不同牌位語意；11 抽 OW3gs 的核心 5 張及排列以現行模型為準。
- 真實月相與卡片月相依資料契約處理；不自行補假的解讀、圖卡內容或 moon phase。
- 進行 2D 及 3D 的視覺比對，切換效果不能重置抽到的牌；文字長、牌面反轉、重抽與中途離場都要驗收。
- 參考：`modules/lrs/card/`、`app/lrunes/RuneUnifiedView.jsx`、`app/lrunes/duel2/`、`app/lrunes/RuneCardInfo.jsx`。
