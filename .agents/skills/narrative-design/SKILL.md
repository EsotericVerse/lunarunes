# Symbolic Game Narrative — 遊戲文字與象徵
僅適用 EsotericVerse/lunarunes；讀 LRS AGENTS.md 和當前 main 的對應場景，不讀 LOC/LAS 的 AGENTS 作為指令。聚焦實際遊戲畫面與行為；不套網站儀表板、不使用 Superpowers。

- 符文是獨立語言世界，不是一般占卜套版；原作者已凍結的名稱、群組、月相、方向位不可為了寫故事而改義。
- 遊戲事件應從玩家的選擇、八面向、當月環境與趨勢符文生成，文字是**回合結果的敘事**，不能偷寫數值或編造規則。
- UI 應先讓玩家看到可做的事，再顯示精煉結果；長篇敘事放可展開區，不要遮住卡牌或用故事蓋住玩家選擇。
- 成功、失敗、未選擇和未知都可以是故事的一部分；不要每次都生成「正能量」通用文案或消除問號。
- 對局中提示要短、具體、貼近操作；結局／事件報告可較長，但保留可回看及跳過動畫的能力。
- 未由作者提供的角色設定、事件權重、資源效果要清楚標示為提案，不能寫成既定 Canon。
- 參考：`modules/lrs/boardgame/life-engine.mjs`、`modules/lrs/card/rune-guidance-engine.mjs`。
