# Accessible Games — 保留遊戲美感而可操作
僅適用 EsotericVerse/lunarunes；讀 LRS AGENTS.md 和當前 main 的對應場景，不讀 LOC/LAS 的 AGENTS 作為指令。聚焦實際遊戲畫面與行為；不套網站儀表板、不使用 Superpowers。

- 每個依賴拖拉／旋轉／長按的動作都要有等價按鈕或鍵盤操作；焦點順序符合牌陣／回合順序，不因視覺位置改變而亂跳。
- 正／半正／半逆／逆與八群組不能只用顏色區分，需文字、位置、圖樣或可讀名稱輔助。
- 對比度與字體要在華麗粒子、光暈和 3D 背景之上仍能閱讀；解牌文字能滾動，不被特效遮蓋。
- `prefers-reduced-motion` 下避免強迫旋轉、閃爍、鏡頭衝刺，保留必要的「抽中／已確認」結果回饋。
- 手機需處理安全區、縮放、觸控誤點、橫直向；盲目縮小整個桌面畫面不算完成。
- 以真實情境驗收：不用滑鼠也能完成一次抽牌、不看色彩也能辨認方向位、低動態能完成同一回合。
